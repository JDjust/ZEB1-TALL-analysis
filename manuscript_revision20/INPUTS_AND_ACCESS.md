# Inputs and lawful source access

The new-analysis script expects analysis/source_inputs, analysis/source_data and analysis/results under this directory; the renderer expects source_data and completed analysis result tables at its parent level. The code retains the accepted independent patient/donor units, locked definitions and negative/mixed outcomes. This candidate includes no new data redistribution.

Principal sources: Pölönen Synapse syn54032669 (1,309 prognostic-analysis objects; the project also has 1,335 expression samples); Wiggers GSE248287, with original human sequencing under dbGaP phs004269.v1.p1; Lim processed CELLxGENE collection 962df42d-9675-4d05-bc75-597ec7bf4afb and original managed EGA records; NOPHO GSE272023 (public processed count matrix; source consent does not permit original raw files to be deposited); normal Yayon CELLxGENE fc19ae6c-d7c1-4dce-b703-62c5d52061b4, PRJEB77091, EGAD00001015384 and GSE271304; AIIMS GSE216117; published India/St Jude resources.

Database visibility does not grant redistribution rights. Obtain the appropriate source records, consent/access terms and exact processed-input schema before replay. Statistical and plotting environments are separately pinned. The code license, when selected, will cover author-owned scripts only and will not relicense source data, imported third-party libraries or upstream materials.
