# Data and permissions

The complete retained local inputs are kept outside the GitHub code package. Set `ZEB1_DATA_ROOT` to `D:/_bioinformation/ZEB1/data/analysis` on the original workstation, or the equivalent existing analysis directory elsewhere. The renderer reads `total/rebuild_2026/data` under that directory. No Hulu download is required or performed.

The accession registry is inherited and indexed; official releases, licensing and cross-cohort independence have not all been independently rechecked. Patient-level tables, raw/processed matrices, H5AD/RDS and clinical predictions are excluded irrespective of file size. sample_metadata.schema.csv is an empty schema, not invented samples. The frozen 100-gene set is a project-derived definition; it is not patient data. GitHub publication does not change the repository's existing visibility.
